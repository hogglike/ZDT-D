# Hogg — помощник часов 0.1.0

Экспериментальный русскоязычный помощник для телефона Android и часов Wear OS.
Это отдельные приложения: обновлять APK ZDT-D или прошивать ZIP модуля не нужно.

## Что умеет

- Записать вопрос на часах (до 25 секунд) или принять текст.
- Передать вопрос сопряжённому телефону через Google Play services Data Layer, включая Bluetooth.
- На телефоне распознать русский голос через Groq Whisper и получить короткий ответ ИИ.
- Вернуть ответ на часы и прочитать его русским голосом, если он установлен в системе.
- Продолжать разговор, начать новый, открыть последние восемь ответов и отменить запрос.
- Проверить связь с телефоном и отдельно проверить ИИ на телефоне.

Телефон выполняет все запросы к ИИ. На часах не требуется вход в Gemini.
Это помощник для вопросов и ответов. Будильники, сообщения, управление устройствами и «Окей Google» пока не реализованы.

## Установка

1. На телефон установи **Hogg-Assistant_phone_0.1.0.apk**.
2. На часы установи **Hogg-Assistant_wear_0.1.0.apk**. APK телефона на часы ставить не нужно.
3. Телефон и часы должны быть сопряжены в Galaxy Wearable. На обоих нужны сервисы Google Play.
4. Приложения подписаны одним сертификатом и имеют одинаковый package name — это требуется для связи между ними.

### Установка APK на часы с компьютера

Если APK на часы ещё не устанавливал:

1. На часах открой сведения о ПО и несколько раз нажми на версию ПО, чтобы включить меню разработчика (названия зависят от версии One UI Watch).
2. В меню разработчика включи отладку по Wi-Fi / беспроводную отладку. Временно подключи часы к Wi-Fi.
3. В разделе сопряжения с кодом посмотри адрес, порт и код.
4. На ПК распакуй официальные Android Platform Tools: https://developer.android.com/tools/releases/platform-tools
5. Открой терминал в папке platform-tools и выполни, подставив адреса именно с часов:

```text
adb pair IP_ЧАСОВ:ПОРТ_СОПРЯЖЕНИЯ
adb connect IP_ЧАСОВ:ПОРТ_ОТЛАДКИ
adb install -r Hogg-Assistant_wear_0.1.0.apk
```

Порт сопряжения и порт отладки обычно разные. Положи APK рядом с adb или укажи полный путь к APK.
После установки выключи отладку. Для проверки Bluetooth можно снова выключить Wi-Fi на часах.

## Бесплатное подключение ИИ

1. Открой https://console.groq.com/keys и создай личный API-ключ на бесплатном тарифе Groq.
2. Открой **Hogg — помощник часов** на телефоне, вставь ключ и нажми **Сохранить настройки**.
3. Оставь модель по умолчанию `qwen/qwen3.8-27b`, указанную в текущей документации бесплатного тарифа.
4. Нажми **Проверить ИИ**. Должен появиться русский ответ.
5. Нажми **Включить связь с часами** и выдай разрешения на устройства поблизости и уведомления.
6. На часах открой **Hogg — помощник**, нажми **Проверить телефон**, затем **Задать вопрос**.
7. Произнеси вопрос и нажми **Отправить вопрос**. Если не нажать, запись завершится и отправится через 25 секунд.

Бесплатный API всё равно требует регистрации и ключа. Приложение не оформляет подписку, не подключает оплату и не переходит автоматически на другой сервис. Доступность регистрации и API из конкретной сети проверяется на телефоне. Если Groq отказывает из-за региона, приложение показывает отказ и не обещает обойти его.
Лимиты и модели могут изменяться: https://console.groq.com/docs/rate-limits
Для бесплатного варианта не добавляй платёжные данные и не включай платный тариф.

## Использование с ZDT-D

При необходимости добавь **Hogg — помощник часов** (`ru.hogglike.watchassistant`) в свой DNS-профиль или VPN-режим ZDT-D.
Приложение использует обычное соединение телефона и не меняет маршруты, DNS, системную точку доступа или настройки Samsung.
Сначала добейся ответа кнопкой **Проверить ИИ** на телефоне. Если этот тест не проходит, проверять голос на часах ещё рано.

## Если не отвечает

- **Телефон не найден:** проверь сопряжение, Bluetooth, обе установки и одинаковые версии APK.
- **Включи связь на телефоне:** запусти Hogg и включи связь. После перезагрузки телефона её нужно включить снова.
- **Нет ответа после блокировки:** проверь ограничения фоновой работы Hogg в настройках батареи OnePlus.
- **Нет русского голоса:** текст ответа остаётся доступен; установи русский голос в системной службе озвучивания часов.
- **Лимит Groq:** подожди. Автоматических повторных платных запросов нет.
- **Ошибка DNS:** проверь доступ к `api.groq.com` с телефона и назначение Hogg в ZDT-D.

## Данные и ограничения

Ключ хранится зашифрованным через Android Keystore только на телефоне и не отправляется на часы. Резервное копирование данных приложений выключено. Голосовая запись отправляется через телефон в Groq для распознавания; текст вопроса и ограниченный контекст разговора отправляются в Groq для ответа. Учитывай правила сервиса: https://console.groq.com/docs/your-data

Микрофон включается только вручную. Запись в кэше часов удаляется после отправки или отмены. Полученный Data Item с аудио удаляется телефоном после обработки; Data Layer может временно хранить синхронизируемые данные. Последний ответ синхронизируется для получения после краткого разрыва связи. История на часах и последние три пары вопрос/ответ на телефоне хранятся локально. Очистка истории часов не удаляет контекст телефона; **Новый разговор** начинает отдельный контекст.

Повторные события одного запроса не запускают обработку второй раз; старые запросы отклоняются. Нет скрытого опроса сервиса, рекламы или аналитики приложения.

Проверки сборки: реальная передача HTTP на локальный тестовый сервер, формат русского запроса и аудио, запрет перенаправлений с ключом, лимит 429 без повтора, отмена, повторные события и срок годности запроса, Android lint, сборка и подписи обоих APK.
Физические часы и личный ключ пользователя недоступны разработчику: качество распознавания, русская озвучка и работа при заблокированном OnePlus требуют проверки после установки.

## Сборка из исходников

JDK 17, Gradle 8.9, Android SDK 35:

```text
gradle -p watch-assistant :common:test :phone:testReleaseUnitTest :phone:assembleRelease :wear:assembleRelease
```

GitHub Actions: `.github/workflows/watch-assistant.yml`. Он подписывает пару APK существующим сертификатом репозитория через уже настроенные секреты, не меняя их и не меняя сборку модуля ZDT-D.
