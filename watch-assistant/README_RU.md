# Hogg — мост Gemini 0.2.2

Экспериментальный мост Galaxy Watch7 → телефонный Gemini → ответ на часах. Без API-ключей и без обращения к Groq/Grok: вопрос вводится в настоящий Gemini на телефоне через Android Accessibility, ответ считывается из его интерфейса. Используется текущий аккаунт и текущий чат Gemini. Лимиты — как у твоего Gemini.

**Подтверждено пользователем:** на его телефоне Gemini отвечает при блокировке. **Пока не подтверждено на устройстве:** ввод вопроса и считывание ответа этим мостом при блокировке. Некоторые версии Gemini разрешают голосовой ответ, но требуют разблокировки для клавиатуры. Мост сообщит об этом; обхода блокировки нет. Телефон может включать экран при вызове помощника.

Это отдельные приложения, ZDT-D 4.2.0-mod34 и его DNS/VPN/раздача не меняются. Старые APK Hogg 0.1.0 использовали другой ИИ; нужно обновить **оба** APK до 0.2.2. Сертификат и package сохранены, обновление устанавливается поверх 0.1.0.

## Сначала проверка на телефоне

1. Установи `Hogg-Assistant_phone_0.2.2.apk` на смартфон.
2. Убедись, что телефонный Gemini сам отвечает по-русски, выбран помощником по умолчанию и разрешён на экране блокировки. Сохрани рабочие назначения Google/Gemini в ZDT-D.
3. Открой **Hogg — мост Gemini** → **Включить доступ к Gemini**. Прочитай описание доступа и включи сервис в специальных возможностях Android.
4. Если Android не разрешает включение: настройки приложения Hogg → меню ⋮ → **Разрешить ограниченные настройки**, затем вернись в спецвозможности. На прошивках названия могут отличаться.
5. Нажми **Включить связь с часами**, разреши устройства поблизости и уведомления. На телефоне появится постоянное уведомление.
6. Нажми **Тест сейчас** с несекретным вопросом. Если обычный вызов не открыл Gemini, включи **Вызов помощника через root**, дай Hogg разрешение в ReSukiSU и повтори один тест. Root используется только для фиксированных клавиш включения экрана и вызова помощника.
7. Вернись в Hogg: результат теста сохраняется. Затем нажми **Тест через 10 секунд**, заблокируй телефон и подожди ответ. Разблокируй и проверь результат в Hogg.

При неизвестном интерфейсе мост останавливается с диагностической ошибкой. Он вводит команду только в поле с распознанной подписью вопроса Gemini, не заменяет существующий черновик, не подтверждает дополнительные действия и не повторяет отправку автоматически. Команда, уже принятая Gemini, может выполниться даже после отмены в Hogg.

## Диагностика, если тест не прошёл

Нажми **Записать интерфейс Gemini · 60 секунд**, прочитай уведомление, затем запусти **один** тест при блокировке. После теста нажми **Скопировать диагностику**. Если вместо теста хочешь показать обычный экран Gemini, в течение записи вызови его вручную и задай несекретный вопрос. Отчёт покажет доступные подписи кнопок, поля и ответ для адаптации к твоей версии.

Запись содержит текст видимого интерфейса Gemini, включая видимую историю. Она хранится локально и автоматически никуда не отправляется. Проверь её перед отправкой. Удалить можно кнопкой **Удалить диагностику**. Без включения записи сохраняются только технические сведения об окне и результат собственного теста.

## На часах

1. Установи `Hogg-Assistant_wear_0.2.2.apk` именно на часы, не на телефон.
2. Телефон и часы должны быть сопряжены через Galaxy Wearable. Открой Hogg на часах → **Проверить телефон**. Эта кнопка проверяет связь и доступ к Gemini, а не работоспособность ответа.
3. Для первой проверки нажми **Ввести текст**, отправь короткий вопрос.
4. Для голосового вопроса нажми **Продиктовать**. Используется системный распознаватель часов с языком `ru-RU`. Проверь распознанный текст и нажми **Отправить**.
5. Ответ показывается на экране и может озвучиваться через русский TTS часов. Если голосовой ввод или русский TTS на часах недоступен, остаётся текстовый вариант. Распознавание может требовать доступа часов к интернету.

**Очистить экран** очищает только экран Hogg, чат Gemini на телефоне сохраняется. **История** хранит последние восемь ответов локально на часах. Длинный ответ ограничен 6000 символами, озвучка — 3500. Запрос заканчивается ошибкой по таймауту, а не уходит на повторную отправку после восстановления связи.

## Установка на часы без ПК через Termux

На часах: Настройки → Сведения о часах → Сведения о ПО → несколько нажатий на «Версия ПО» включают режим разработчика. В параметрах разработчика включи отладку ADB и беспроводную отладку. Подключи часы и телефон к одной Wi-Fi сети. На экране беспроводной отладки отдельно показаны порт сопряжения и порт подключения — они обычно разные.

На телефоне установи актуальный Termux, положи APK часов в Download, выполни:

```sh
pkg install android-tools
termux-setup-storage
adb pair IP_ЧАСОВ:ПОРТ_СОПРЯЖЕНИЯ
# Введи код, показанный на часах.
adb connect IP_ЧАСОВ:ПОРТ_ПОДКЛЮЧЕНИЯ
adb install -r /sdcard/Download/Hogg-Assistant_wear_0.2.2.apk
```

Замени IP/порты на значения с часов. Если сеть изолирует устройства, используй сеть, где они видят друг друга. После установки выключи отладку. Для работы Hogg отладка не нужна, связь идёт через Wear Data Layer сопряжённых устройств.

## Что проверено при сборке

CI собирает оба APK, выполняет Android Lint и unit-тесты границ протокола и извлечения ответа: старый ответ не выдаётся за новый, незавершённая генерация не считается ответом, кнопки подтверждения/отзыва не считаются отправкой, повторные и устаревшие команды не принимаются. APK подписываются одним существующим сертификатом репозитория. Сборка и unit-тесты не заменяют тест на твоих реальных телефоне и часах.

Если OnePlus выгружает Hogg, разреши ему фоновую работу в настройках батареи. После перезагрузки телефона связь включается вручную. Этот мост зависит от интерфейса Google/Gemini и может потребовать адаптации после обновления приложения.
