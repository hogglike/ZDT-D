# ZDT-D 4.3.0-mod39 — Zapret, VPN-виджет и Telegram

Версия без экспериментального проекта для часов. Установи APK и обнови модуль ZDT-D-Test, затем перезагрузи телефон. Идентификаторы приложения и модуля прежние; настройки сохраняются. Подпись сборки не меняется.

## Автоматический подбор Zapret

Инструменты → Анализ и тестирование → тестер nfqws/nfqws2 → «Автоподбор Zapret».

1. Останови основной ZDT-D и другие VPN. Выбери ядро nfqws или nfqws2.
2. Укажи 1–4 HTTPS-адреса, которые должны открываться. По умолчанию — YouTube и Discord. Адреса без логинов/паролей; порт 443.
3. Выбери первые 12, 30 или все (до 100) стратегии установленного набора. Запусти автоподбор.
4. Он сравнит доступность без стратегии и сделает по две попытки для каждого адреса с каждой стратегией. Успешные варианты показываются первыми, с суммарным временем всех запросов.
5. Нажми успешный вариант, выбери существующий профиль и примени. Сохраняется резервная копия прежних аргументов. Запусти ZDT-D и проверь приложение.

Подбор сам не переписывает рабочие профили. Результаты и адреса сохраняются после закрытия экрана. При смене сети проверка останавливается. Есть кнопка остановки в уведомлении. Максимум сессии — 30 минут. Временная стратегия имеет отдельный сторож: при смерти процесса приложения или превышении 3 минут её процесс и правила удаляются. Остановка тестера больше не завершает все процессы nfqws: только принадлежащий ему процесс.

HTTP 2xx/3xx в двух попытках — проверка HTTPS, а не гарантия воспроизведения видео, QUIC, звонков или работы при смене фильтрации у оператора. Если все адреса работали без стратегии, результат не доказывает необходимость обхода. Автоматической смены аргументов работающего профиля в фоне нет: повтори подбор после изменения сети и выбери подходящий вариант. DNS-профили и назначенные приложения при применении стратегии сохраняются.

## VPN-виджет

- Вверху — режим, текущий сервер и состояние проверки.
- Зелёный означает успешную проверку. Применение без проверки отображается жёлтым.
- Под режимами видно «Авто» или название выбранного сервера; нажатие открывает выбор с возвратом к авто.
- Нажатие режима запускает его без перехода в настройки. Повторное нажатие уже активного режима не дёргает подключение.
- «Повторить» переподключает текущий режим; «Отключить»/«Отменить» останавливает его.
- Строка приложений открывает настройки нужного режима. Шестерёнка открывает общие настройки режимов.
- Кнопка обновления серверов и совмещённый виджет проверки связи сохранены. Если старый виджет обрезан, увеличь его высоту или добавь заново.

## Telegram через подписку

Инструменты → «Telegram через подписку».

1. Добавь рабочую VPN-подписку в «Подписки».
2. Выбери ручной сервер либо автоперебор. В авто можно отметить нужные серверы; пустой выбор означает все поддерживаемые серверы включённых подписок, включая новые.
3. Нажми «Подключить». После проверки нажми «Открыть в Telegram» и подтверди добавление SOCKS5 в Telegram.
4. В Telegram включи этот прокси. Он доступен только на этом телефоне: 127.0.0.1:19978, с автоматически созданным паролем. Ссылка доступна и для копирования.

Используется отдельное ядро sing-box; Opera, Webshare, TGWS и слот Android VPN этому инструменту не нужны. Трафик расходуется по выбранной VPN-подписке. Интернет других приложений и DNS-маршруты инструмент не перенастраивает. Для работы нужен запущенный основной ZDT-D; его остановка приостанавливает и Telegram-прокси.

Проверка раз в минуту открывает HTTPS web.telegram.org через выбранный сервер. После двух ошибок подряд авто пробует следующий сервер. При общем сбое попытка повторяется через минуту; есть ручное переподключение кнопкой «Подключить». Удалённые серверы пропускаются, явный выбор остальных сохраняется. После изменения сети адреса узлов разрешаются заново.

Зелёная проверка не подтверждает доставку сообщений или работу звонков. Проверяй их в самом Telegram; для звонков есть его переключатель «Использовать для звонков». Если выключаешь инструмент, выключи локальный прокси и в Telegram, иначе Telegram продолжит подключаться к остановленному порту.

## Прокси Opera

«Для API Opera · весь список» теперь добавляет прокси к текущим, убирает дубликаты и соединяет запятыми без пробелов. Другие аргументы сохраняются. Смена цепочек SNI на ByeDPI по умолчанию выключена. Страница каталога прокручивается целиком.

Эта версия не обещает восстановить доступность серверов Opera. Telegram имеет независимый путь через VPN-подписку. Часы и мост Gemini не возвращались.

## Проверки

Сборка Release, тесты Rust/Kotlin и проверка настоящего SOCKS5-обмена через ядро: пароль обязателен, недоступный сервер не приводит к прямому обходу прокси, переключение восстанавливает передачу данных. Реальную работу стратегий у твоего оператора и сообщения/звонки Telegram нужно проверить на телефоне.
