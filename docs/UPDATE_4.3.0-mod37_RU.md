# ZDT-D 4.3.0-mod37 — автоматический перебор прокси Opera

## Что исправлено

В mod36 каталог позволял выбрать один прокси вручную. В mod37 появился режим
«Авто — весь список»: Opera пробует сохранённые прокси по очереди при установлении
соединений. Последний успешный идёт первым, при отказе используется следующий.
Проверяется не только TCP-порт, но и авторизация HTTP/SOCKS5, а для соединений Opera —
полный TLS/CONNECT-туннель. При отказе всех кандидатов выдаётся ошибка без прямого
обхода списка. Уже открытые соединения не переносятся; следующие используют рабочий сервер.

Каждая попытка ограничена шестью секундами и общим таймаутом запроса Opera.
Для нового соединения выполняется один круг; штатные повторные запросы Opera
снова запускают перебор. Список не предполагает одновременное подключение ко всем
десяти прокси и не складывает их скорость.

Новая кнопка «Авто — использовать весь список в Opera» применяет каталог ко всем
существующим SNI-записям. В редакторе SNI доступны «Авто» и ручной выбор; переход
на один прокси сохраняет список Авто. При изменении каталога примени список снова.

В разделе «Прокси» отображается состояние Авто и причины отказа отдельных серверов.
Состояние «Соединение установлено» подтверждает установление последнего туннеля,
а не постоянную доступность каждого сайта. Пароли и токены в статус не включаются.

В режиме Авто запросы авторизации Opera тоже идут через выбранный внешний прокси.
Отдельный старый API-прокси поверх него не добавляется. Настройки API-прокси для
других режимов сохранены.

Сообщение t2s `connect/greeting/auth failed` заменено понятным описанием:
это недоступность локального SOCKS-прокси или отказ согласования/авторизации,
а не доказательство неверного пароля Webshare.

## Как включить

1. Установи APK поверх mod36 и обнови модуль через встроенный установщик или PLAIN ZIP в ReSukiSU. Перезагрузи телефон.
2. Открой «Прокси». Ранее импортированный каталог сохраняется; повторный импорт не нужен.
3. Нажми «Авто — использовать весь список в Opera», затем «Применить Авто».
4. Перезапусти ZDT-D один раз. Открой приложение из списка Opera и посмотри статус в разделе «Прокси».

Для отдельного SNI: Opera Proxy → SNI → карандаш → «Из списка прокси» → «Авто — весь список», сохрани запись и перезапусти ZDT-D.

Если все серверы недоступны, проверь протокол экспорта, действительность логина/пароля,
доступность адресов и ограничения аккаунта Webshare. Автоперебор не исправляет одинаковые
неверные учётные данные или запрет соединений для всего списка.

## Проверки

Release-сборка `build.yml` на `copilot-polish`: реальные локальные HTTP CONNECT и
SOCKS5 с авторизацией, отказ 407/403, таймаут, отмена запроса, приоритет последнего
рабочего, повтор полного TLS-рукопожатия, отсутствие секретов в статусе и отсутствие
прямого обхода. Go-тесты выполняются с детектором гонок. Затем собираются ARM64/ARM32
и три варианта APK с Android unit-тестами. Подключение с личными серверами Webshare
нужно проверить на телефоне: учётных данных и сети телефона в сборочной среде нет.
