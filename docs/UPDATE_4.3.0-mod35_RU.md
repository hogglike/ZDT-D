# ZDT-D 4.3.0-mod35 — обновление без функций для часов

Основа: официальный ZDT-D V4.3.0 (`249beb4`) и последняя наша сборка без часов,
4.2.0-mod31 (`5477ac6`). Номер мода продолжает общую последовательность.

Сохранены рабочие DNS-профили для приложений, исправление системной точки доступа,
Opera Proxy, подписки, режимы «Белый», «Обычный», «Браузер», ручной выбор и
автоперебор серверов, проверка задержки, автообновление и виджеты.
Также сохранён запуск приложения без искусственной задержки.

Из 4.3.0 перенесены интерактивный VPS-терминал, улучшения переходов и очистки кэша,
исправления установки и интерфейса, поддержка своего промежуточного прокси для Opera.
Режим DNS для часов и отдельные приложения Hogg в эту сборку не входят.

## Обновление на OnePlus с ReSukiSU

1. Сохрани резервную копию настроек через ZDT-D.
2. Останови ZDT-D. Если был включён отдельный режим DNS для часов, выключи его.
3. Установи `ZDT-D-Test_4.3.0-mod35.apk` поверх нашего приложения, без удаления данных.
4. В ReSukiSU установи `ZDT-D-Test_4.3.0-mod35_PLAIN.zip` поверх **ZDT-D-Test**.
5. Перезагрузи телефон, открой ZDT-D и проверь выбранные DNS-профили и VPN-режимы.

PLAIN ZIP предназначен для установки через root-менеджер. APK — полная root-сборка;
в ней также встроен модуль для установки через приложение. Достаточно одного способа
обновления модуля. Если используешь ZIP в ReSukiSU, повторно ставить модуль из APK не нужно.
Не включай одновременно официальный модуль ZDT-D и наш ZDT-D-Test.

Идентификаторы нашего APK и модуля сохранены. Установщик переносит существующую
`working_folder` при обновлении; удалять подписки и заново назначать приложения не нужно.
При переходе с mod32–mod34 настройки функций часов больше не используются.
Отдельные APK Hogg можно удалить.

Версия в APK, модуле, диагностике и именах файлов: **4.3.0-mod35**, versionCode **43035**.
Подпись APK остаётся существующей подписью нашего форка.
