# ZDT-D 4.2.0-mod22

## Baselines and preserved behavior

- Upstream: tag `V4.2.0`, commit `063e095210adfc84cfbbd2c82e7b3708fb8e3c4f`.
- Previous mod: build21, commit `1f2a4fdc81f94a167ca6b7841f9b6322aa470a20`.
- Keep the existing per-app DNS implementation, raw Android DNS Binder bridge,
  profile-local listener, netd/UID routing and forwarding-ownership fix.
- Keep `suspend_for_tethering`: enable it, stop/start ZDT-D, then start the hotspot.
- No claim that this upgrade fixes DNS after Wi-Fi/mobile handover. Device testing
  is still needed; host/static tests do not prove Android networking behavior.

## Compatibility and versioning

- DNS profiles use tun2socks 2.7.0 long CLI flags (`--device`, `--proxy`, `--loglevel`).
- Keep both DNS Binder and HEV JNI R8 keep rules.
- Keep module ID `ZDT-D-Test` and app ID `com.hogglike.zdtd.test`.
- Preserve the official TGWS plugin IPC namespace; do not bypass signature checks.
- Use `version=4.2.0-mod22`, `versionCode=42022`, `upstreamVersion=4.2.0`,
  `modVersion=22`. The module and APK both derive their version from module.prop.
- User-facing artifacts: `ZDT-D_4.2.0_mod22.apk`,
  `ZDT-D_4.2.0_mod22_PLAIN.zip`, `ZDT-D_4.2.0_mod22_FINAL.zip`.
- For ReSukiSU install PLAIN, not FINAL. The existing working-folder preservation
  stays enabled. Never enable the normal module and Test module simultaneously.

## Validation and install checklist

- Run `python3 scripts/test_variant/test_prepare_test_variant.py` on untransformed
  source; test version consistency, package isolation, plugin IPC and idempotence.
- Validate Release with `.github/workflows/build.yml` on `copilot-polish`.
- Before installation back up the existing `working_folder`; stop ZDT-D, update
  the matching APK and PLAIN module, reboot, then verify saved profiles.
- On the phone test actual DNS replies, Gemini/Grok/ChatGPT, Wi-Fi/mobile
  transitions, stop/start cleanup and ordinary hotspot with DNS suspended.
- Keep build21 available for rollback. Do not replace the known device baseline
  until these checks pass.
