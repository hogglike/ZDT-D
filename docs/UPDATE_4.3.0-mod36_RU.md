# ZDT-D 4.3.0-mod36

Основа — наша 4.3.0-mod35 без функций для часов.

## Что изменилось

- Отдельный раздел «Прокси» на вкладке инструментов, рядом с подписками.
- Импорт TXT Webshare (`адрес:порт:логин:пароль`) и вставка списка строк. Все десять серверов можно добавить сразу. Поддерживаются также готовые URL HTTP, HTTPS, SOCKS5 и SOCKS5H. Для строк Webshare выбирается HTTP или SOCKS5.
- Предварительный просмотр импорта: количество новых серверов, повторов и номера неверных строк. Импорт добавляет серверы; существующие записи сохраняются, дубликаты пропускаются. Ограничение — 1 МБ и 1000 серверов.
- В редакторе Opera Proxy → SNI появилась кнопка «Из списка прокси». Она открывает каталог и подставляет выбранный сервер в «Свой» внешний прокси. Для m.vk.com и vk.com выбор сохраняется отдельно. Поле URL и пароли в каталоге скрыты.
- В настройках VPN-режимов выбранные приложения показаны сверху, сразу под выбором режима. В окне выбора отмеченные приложения идут первыми. Для чёрного списка они подписаны как исключённые.

Каталог не меняет SNI автоматически и не выполняет перебор внешних прокси. После выбора сохрани запись SNI и перезапусти ZDT-D. Удаление записи из каталога не удаляет уже сохранённые настройки Opera.
API-ключ Webshare вставлять в список не нужно: используй TXT-выгрузку. Автоматическая синхронизация через REST API в эту версию не входит.
Каталог хранится в приватных данных Android-приложения; выбранный URL передаётся в существующую конфигурацию Opera. Импорт не отправляет данные наружу. Каталог не включён в резервную копию root-модуля — сохрани исходный TXT для повторного импорта.

Интеграция ИИ пока только рассматривается; сетевых запросов к ИИ и хранения API-ключей нет.

## Установка

Установи `ZDT-D-Test_4.3.0-mod36.apk` поверх нашего APK. Обнови модуль через встроенный установщик или `ZDT-D-Test_4.3.0-mod36_PLAIN.zip` в ReSukiSU, затем перезагрузи телефон. Перед обновлением сохрани резервную копию настроек. APK и модуль имеют прежние идентификаторы; данные root-модуля переносятся установщиком.

Версия **4.3.0-mod36**, versionCode **43036**. DNS-профили, сетевые маршруты, загрузочные скрипты и действия VPN-виджетов не менялись.
